# Ranges, not exact pins. Several of these ship compiled extensions
# (pydantic-core, numpy, scipy, Pillow, torch), and a wheel only exists for the
# Python versions that were current when it was released. Pinning such a package
# exactly means that on a newer Python pip finds no wheel, falls back to
# building from source, and fails on a missing Rust or C++ toolchain. Bounds
# below let pip choose a build that exists for your interpreter.
#
# For byte-identical installs across machines, generate a lock file from this
# and install that instead:
#
#   pip install -r requirements.txt
#   pip freeze > requirements.lock.txt      # commit this
#   pip install -r requirements.lock.txt    # on other machines
